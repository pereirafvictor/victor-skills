# Victor Skills

Skills de Claude Code para operação de arbitragem de mídia programática.
Cada skill automatiza uma etapa do dia a dia: subir campanha, monitorar performance, diagnosticar conta.

## Skills disponíveis

| Skill | O que faz | Status |
|-------|-----------|--------|
| subir-campanha | Sobe campanha de tráfego no Meta Ads via 1 frase | ✓ |

✓ = disponível

## Como instalar uma skill

```bash
git clone https://github.com/pereirafvictor/victor-skills.git
cd victor-skills/skills/<nome-da-skill>
# leia o README dentro de cada skill
```

## Contexto da operação

Arbitragem de mídia programática: tráfego comprado no Meta Ads → blogs monetizados via Google Ad Manager.

Blogs: portaldoplayer.com · universodolook.com
